# Daftar Proyek Aktif & Konteks

## 1. ClipForge (Flagship Project)
- **Lokasi**: `/Users/macbookpro/Kerja/Project/clipForge`
- **Deskripsi**: Web-based Non-Linear Video Editor (NLE) bergaya CapCut desktop dark mode.
- **Teknologi**: React, TypeScript, Tailwind CSS, Zustand, WebGL/Canvas, IndexedDB (ClipForgeMediaDB).
- **Fitur Utama**:
  - Multi-track timeline (video, audio, text/subtitle, stickers).
  - Multi-select timeline clips (Shift/Cmd/Ctrl+Click, Ctrl+A select all, batch delete).
  - Dynamic duration expansion via HTML5 media metadata on upload.
  - AI Auto-caption menggunakan 9Router 'my-combo' (visual & speech context untuk natural Indonesian timestamped subtitles).
  - CapCut dark mode 4-quadrant layout (top-left assets, top-center player, top-right inspector, bottom timeline).
  - Cyan accent (`#00e5ff`) + dark glassmorphism.
