# Tech Stack & Ekosistem

## Frontend
- React 18+ (Hooks, Context, Concurrent)
- TypeScript (Strict mode)
- Tailwind CSS (Utility-first, Glassmorphism)
- State Management: Zustand (ringan, unopinionated)
- Canvas / Media: WebGL, HTML5 Canvas, Web Audio API, WebCodecs

## Backend & Services
- Node.js / Bun / Python
- REST API & WebSocket
- Database: IndexedDB (client-side blob/media), LocalStorage (metadata), PostgreSQL / SQLite
- Cloud & AI: 9Router ('my-combo'), OpenAI-compatible endpoints, WebGPU (future)

## Tooling & OS
- macOS (Apple Silicon / Darwin)
- Terminal: zsh, Homebrew, git, gh
- Agent: Hermes Agent (Nous Research)
- Knowledge Base: Obsidian Vault (filesystem-first Markdown)
